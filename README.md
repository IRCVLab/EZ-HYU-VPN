# EZ-HYU-VPN

한양대학교 VPN 연결과 자동 재연결을 간편하게 제공하기 위한 macOS,
Windows, Ubuntu용 클라이언트 프로젝트입니다.

## 배포 중단

현재 구현과 실기기 검증이 완료되지 않아 **모든 설치 파일 배포를
중단했습니다.** GitHub Releases의 기존 설치 파일과 릴리스 태그도 모두
삭제했습니다.

검증이 완료된 새 버전을 공개하기 전까지 이 저장소의 코드는 개발용이며,
설치하거나 실제 VPN 연결에 사용하지 마세요.

새 배포는 각 운영체제에서 설치, 실제 연결, 세션 만료, 네트워크 이동,
자동 재연결, DNS/라우팅 복구, 업그레이드 및 제거 검증이 모두 완료된 뒤에만
제공합니다.
